# Official Guidelines for Rule Authoring & Active Google APIs

## 1. Rule Taxonomy, Language & Budgets (Antigravity `docs/rules.md`)

- **Language Rule:** Author all `AGENTS.md`, `GEMINI.md`, and `rules/*.md` files in concise **Technical English** while preserving the user-facing `pt-BR` communication rule.
- **Directory Rules (`AGENTS.md` / `GEMINI.md`):** Apply to the containing directory and subdirectories (in plugins, `rules/AGENTS.md` stays active with the plugin). **NEVER place YAML frontmatter** in files named `AGENTS.md` or `GEMINI.md`.
- **Modular Rules (`rules/*.md` in `.agents/rules/`, `~/.gemini/config/rules/`, or `plugins/<name>/rules/`):** **REQUIRE** YAML frontmatter with `trigger: always_on | model_decision | glob | manual`:
  - `trigger: glob` requires `globs:` as a single comma-separated string with `**/` relative prefixes (e.g., `"**/*.ts, **/src/**/*.tsx"`).
  - `trigger: model_decision` requires a clear `description:` for on-demand loading without polluting unrelated turns.
- **Anti-Duplication:** Never mirror the same rule in both `~/.gemini/config/rules/` and `~/.gemini/config/plugins/<name>/rules/`; plugin modular rules live exclusively in the plugin `rules/` folder, keeping `always_on` SSOT in the single global rules directory.
- **Strict Caps:** Max **`24,000` bytes (`24 KB`)** per file (after expanding file-include `@` directives, i.e. `@` + `[label](relative.md)` — truncated on line boundaries above the cap) and **`20,000` tokens (`defaultRulesBudget`)** aggregate across global/always-on rules (excess is demoted to file path pointers).

## 2. Active Google APIs, SDKs & Models

- **Active Models (Gemini 4, Decisions, Live, Media & Deprecations):**
  - **Gemini 4 Family (1M unified context, implicit caching `>= 4,096` tokens, no explicit `cachedContents`, `temperature`/`top_p`/`top_k` ignored/deprecated, 64K default or 1M long decode with `background=True`):**
    - `gemini-4-carbon`: maximum reasoning (`thinking_level`: `low`, `medium` default, `high`).
    - `gemini-4-argon`: efficient frontier reasoning (`thinking_level`: `low`, `medium` default, `high`).
    - `gemini-4-hydrogen`: fast, reliable default for code and agents (`thinking_level`: `low`, `medium`, `high` default, **`xhigh`** — `minimal` unsupported; default in `antigravity-preview-09-2026`).
  - **Antigravity IDE/CLI & Orchestrator:** `Gemini 4 Carbon`, `Gemini 4 Argon`, `Gemini 4 Hydrogen` (`Extra` / `--model gemini-4-hydrogen-xhigh` or `--effort xhigh`), **`Orchestrator (Carbon)` / `Orchestrator (Argon)`** (plans in Carbon/Argon, implements in Hydrogen), `Gemini 3.8 Flash`, `Gemini 3.7 Flash`, `Gemini 3.6 Flash`, `Gemini 3.1 Pro`, `Claude Sonnet 5.5 (thinking)`, `Claude Opus 5.5 (thinking)` (`Claude 4.6` and `GPT-OSS-120b` scheduled removal 2026-11-18).

- **Critical Split (`Managed Antigravity Agent` vs. Standard GenAI API):**
  - In **Managed Antigravity Agent** (`antigravity-preview-09-2026` via Interactions API), `generation_config` **rejects (`400`)** `temperature`, `top_p`, `top_k`, `stop_sequences`, and `max_output_tokens` — never inject these fields in that profile.
  - In standard `generateContent` / `interactions.create` calls (`google-genai`, `@google/genai`, `google.golang.org/genai`), `max_output_tokens` is supported and recommended (up to 64K sync or 1M with `background=True`).

## 3. Google ADK Go v2, SkillToolset & Gatekeeper Authoring Invariants

- **ADK Go v2 `workflow` (`google.golang.org/adk/v2/workflow`):** Invoke `workflow.RunNode` (`WithUseSubBranch()`, `WithIsolationScopeFromNodePath()`) exclusively inside `workflow.NewDynamicNode` (`ctx.SubScheduler() != nil`), never inside `FunctionNode`; inside `NewDynamicNode`, never set `ev.Output` on an emitted event while also returning a non-nil typed output; isolate per-invocation circuit-breaker counters under `temp:*` session state keys.
- **ADK Go v2 `SkillToolset` (`skill.Parse`):** Keep `SKILL.md` `metadata:` values strictly as flat `map[string]string` scalars (nested objects or YAML arrays break `yaml.Unmarshal` inside `skilltoolset`) and declare `allowed-tools:` at the top level of YAML frontmatter.
- **Gatekeeper & Pre-Tool Hook Hygiene:** Never write literal retired model identifiers inside `.context/*.md`, `AGENTS.md`, `DESIGN.md`, or `README.md` (refer generically to *"retired legacy 2.5/3.1 preview models"* so static gatekeepers pass); when updating evaluation suites containing adversarial prompt-injection test fixtures, apply targeted `edit_file` hunks on surrounding lines rather than overwriting the full file.
