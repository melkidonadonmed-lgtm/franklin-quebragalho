# Visual Composition, UI/UX, 60-30-10 OKLCH & 3-Layer Shadow Guidelines (9-Axis SSOT)

1. Consult `design-md`, `system-project-auditor` (`v6.0.0`), or [`Preferências de Trabalho com Agentes.md`](file:///C:/Users/melki/dev/notes/Mem%C3%B3ria/Prefer%C3%AAncias%20de%20Trabalho%20com%20Agentes.md).
2. **`60-30-10` Chromatic Ratio & Perceptual `OKLCH` Colors:**
   - **60% Dominant Surface:** `--surface-canvas` (legacy alias `--bg-canvas`) in `oklch()` with `light-dark()` (Dark Mode: $L = 0.16$, zero pure `#000000`).
   - **30% Secondary Structure:** `--surface-sunken` ($L = 0.13$ Dark), `--surface-card` ($L = 0.22$ Dark), and `--surface-elevated` ($L = 0.27$ Dark) with explicit `light-dark()` pairs.
   - **10% Surgical Accent:** `--brand-primary` calibrated via `color-mix(in oklab, ...)` and `oklch(from ...)` restricted to primary CTAs, `:focus-visible`, and `6px`/`2px` indicators (zero neon colors).
3. **Zenith Lighting (90°–120°) & 3-Level Multi-Layer Shadows (`--shadow-elevation-1..3` / `--shadow-elevation-low/medium/high` + `--shadow-inset` / `--shadow-inset-sunken`):**
   - Never use flat single-pass `rgba(0,0,0)` drop shadows. Separate primitives (`--shadow-layer-sm/md/lg`) from semantic tokens (`--shadow-elevation-1..3`, `--elevation-1..3`, `--shadow-elevation-low/medium/high`, `--elevation-low/medium/high`, `--shadow-inset`, `--shadow-inset-sunken`, `--elevation-pressed-inset`, `--shadow-clean-card`) and register utilities in Tailwind v4 `@theme`.
   - Always combine **3 optical layers** across levels 1–3: (1) **Contact Umbra** (short dense occlusion), (2) **Diffuse Penumbra with negative `spread` (`-1px` to `-8px`)**, and (3) **Top Catch-Light (`inset 0 1px 0 0`) + `1px` Perimeter Ring** (plus *Ambient Brand Glow* `0px 0px 12px..24px 0px oklch(from var(--brand-primary) l c h / 0.14..0.24)` in Dark Mode). Use `text-shadow` on titles over media (`.heroTitleOverGradient`) and `filter: drop-shadow()` on transparent SVGs/PNGs (`.menuDropdownShadow`).
4. **Spacing Engineering (`4px/8px` Primitives + Semantic Stitch / Tailwind v4 `@theme`), Concentric Radii & Anti-Collapse:**
   - Enforce `box-sizing: border-box`, logical properties (`inline-size`, `padding-inline`, `margin-block`, `gap`, `display: flow-root`, `.prose > * + *`), primitive scale (`--space-0-5..16`) paired with semantic intent tokens (`--space-inline-icon`, `--space-card-gap`, `--space-card-padding: clamp(1rem, 3cqi, 1.75rem)`, `--space-grid-gap`, `--space-section-inset`), respecting Gestalt Proximity ($\text{Inner Gap} < \text{Card Padding} \le \text{Grid Gap} < \text{Section Inset}$) and Concentric Radii ($R_{\text{in}} = \max(4\text{px}, R_{\text{out}} - P)$).
5. **Flexbox (1D) vs. CSS Grid (2D) vs. Subgrid, Visual Hierarchy, Adaptive Navigation & Fluidity (INP/LCP):**
   - **Layout & Cards:** Macrolayouts (`@media` + CSS Grid `100dvh`, RAM Pattern `repeat(auto-fit, minmax(min(100%, 280px), 1fr))`) vs. Microlayouts (`@container`); Flexbox with `flex-wrap: balance`, `align-items: safe center`, `min-inline-size: 0` (never mix `width` with `flex-basis`); `<article>` Cards with 4 `subgrid` regions (keeping `container-type: inline-size` off the `subgrid` node), `.card:has(> img)`, clickable `a.card-link::after` (`inset: 0`), and `:has(> :checked)` without changing `border-width`.
   - **Hierarchy, Adaptive Navigation & Fluidity:** Fluid `clamp()` typography ($\max \le 2.5\times \min$ for WCAG 200% zoom, `max-inline-size: 60ch–65ch`, `text-wrap: balance/pretty`, `tabular-nums`, `antialiased`, `font-synthesis: none`, **zero UI emojis**); Single-DOM Navigation transitioning from Mobile Bottom Bar (`padding-block-end: env(safe-area-inset-bottom, 0px)`, 3–5 items) to `240px` `100dvh` Sidebar Rail at `>= 48em` + intrinsic Popover (`ResizeObserver` + `popover="auto"`), `<nav aria-label>` (`<= 3`), `aria-current="page"` (non-color indicator `>= 3:1`), Breadcrumbs `<ol role="list">` with silent `::before`; Fitts' Law (`48x48px` on `any-pointer: coarse`, `gap >= 8px`, `touch-action: manipulation`), GPU-only animations (`transform`/`opacity`, `transition-behavior: allow-discrete` declared separately after `transition`), View Transitions, Predictive Back, and `content-visibility: auto`.
