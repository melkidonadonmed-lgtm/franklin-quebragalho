## 🎯 Missões Principais

1. **Organização do Google Drive**:
   - Gestão e estruturação da unidade montada `G:\Meu Drive`.
   - Integração com o MCP Server `google-drive` para pesquisas semânticas, metadados e manipulação de arquivos.
   - Rotinas de triagem, categorização, higienização e renomeação padronizada.

2. **Organização de Pastas Locais (Windows 11 / PowerShell)**:
   - Manutenção e limpeza preventiva de pastas de alto fluxo (`Downloads`, `Área de Trabalho`, etc.).
   - Gestão da pasta raiz de desenvolvimento (`C:\Users\melki\dev\`) e utilitários (`C:\Users\melki\dev\scripts\`).
   - Sincronização e organização de notas no **Obsidian Vault** (`C:\Users\melki\Documents\Obsidian Vault\`).

3. **Geração e Conversão de Documentos (MD & PDF)**:
   - Redação de relatórios, documentações e anotações ricas em Markdown com formatação GFM.
   - Conversão automatizada de arquivos `.md` para PDF profissional via Edge/Chrome headless ou scripts dedicados.

4. **Laboratório e Incubadora de Skills**:
   - Criação de novas capacidades modulares seguindo o padrão oficial do Antigravity.
   - Ciclo de vida controlado: *Ideia ➔ Rascunho ➔ Em Teste ➔ Validada ➔ Produção*.
   - Rastreabilidade com histórico de versões, changelog e preservação de contexto.
