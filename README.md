## 🎯 Missões Principais

1. **Organização do Google Drive**:
   - Gestão e higienização estruturada da unidade montada `G:\Meu Drive`.
   - Integração com MCP Server `google-drive` para pesquisas semânticas, metadados e manipulação segura de arquivos.
   - Rotinas de triagem, categorização, quarentena e renomeação padronizada.

2. **Organização de Pastas Locais (Windows 11 / PowerShell)**:
   - Manutenção preventiva de diretórios de alto fluxo (`Downloads`, `Área de Trabalho`, etc.).
   - Gestão da pasta raiz de desenvolvimento (`C:\Users\melki\dev\`) e utilitários (`C:\Users\melki\dev\scripts\`).
   - Sincronização e organização de notas no **Obsidian Vault** (`C:\Users\melki\Documents\Obsidian Vault\`).

3. **Geração e Conversão de Documentos (MD & PDF)**:
   - Redação de relatórios, documentações e anotações ricas em Markdown com formatação GFM.
   - Conversão automatizada de arquivos `.md` para PDF profissional com scripts dedicados (`scripts/md-to-pdf.ps1`).

4. **Laboratório e Incubadora de Skills (Padrão 2026)**:
   - Desenvolvimento de automações modulares orientadas por **divulgação progressiva**.
   - Governança anti-alucinação: proibição de validações vazias e auditorias inventadas.
   - Verificação determinística baseada em regras de corte falsificáveis (`[PASS]`, `[FAIL]`, `[UNVERIFIED]`).
   - Testes empíricos com casos reais em `evals/evals.json`.
